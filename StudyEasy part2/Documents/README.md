# StudyEasy – Assignment 2

This project is part 2 of my StudyEasy website.  
In Assignment 1, the website was built using only HTML.  
In Assignment 2, I added CSS and responsive design.

---

## Features
- Consistent blue and white color theme
- Navigation bar with hover effects
- Responsive layout for desktop, tablet, and mobile
- Clear structure with header, navigation, main content, and footer

---

## Responsive Design
1. **Breakpoints** – The website adapts to:
   - Desktop (multi-column navigation bar)
   - Tablet (slightly smaller font)
   - Mobile (stacked navigation links, smaller text)

2. **Relative Units** – Used `em`, `rem`, and `%` for spacing and sizing.

3. **Responsive Images** – Images can use `srcset` and `sizes` (not required for this text-only version).
